# Email-ready project summary

Subject: DomainFit — Nugen alignment readiness and architecture planner

I built DomainFit, an open-source developer use-case planner that turns product requirements into a structured alignment plan. It distinguishes stable behavior suited to domain alignment from changing evidence suited to retrieval, private or live data suited to tools, and controls that must remain deterministic or human-reviewed.

The project includes a polished Next.js application, server-only Nugen inference, strict structured-output validation, a resumable Python alignment workflow, reviewed and held-out benchmark formats, base-versus-aligned comparison, automated tests, and candid API developer-experience notes. Alignment and deployment are intentionally excluded from public routes and require explicit local confirmation.

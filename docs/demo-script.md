# 75-second demo script

**0–10 seconds:** “DomainFit turns an AI use case into a tested architecture and alignment plan. It decides where general models, alignment, retrieval, tools, deterministic logic, and human review belong.”

**10–28 seconds:** Open the planner. Enter a support assistant with stable escalation behavior, changing cited guidance, private account data, and approval-gated ticket creation. Show autosave and the progress indicator.

**28–48 seconds:** Submit and open the result. Highlight the hybrid recommendation, confidence, alignment scope, runtime retrieval scope, tool scope, deterministic controls, and document-readiness gaps.

**48–60 seconds:** Edit a benchmark question and export the JSON artifact. Explain that this makes the recommendation reusable rather than conversational advice.

**60–70 seconds:** Open model comparison. Show identical input sent to the Nugen base model and deployed DomainFit aligned model, with latency and usage where available.

**70–75 seconds:** “The public app performs inference only. Paid alignment and deployment remain guarded, resumable local API workflows.”
